# Paradise Nursery – e-Plant Shopping

This repository contains the Paradise Nursery shopping experience, featuring a landing page, product
listing, and cart workflow for houseplants.

Key files:
- `src/App.jsx` – landing page with navigation and call to action.
- `src/App.css` – styling for the hero background and layout.
- `src/AboutUs.jsx` – company overview.
- `src/components/ProductList.jsx` – product catalog with add-to-cart actions.
- `src/components/CartItem.jsx` – shopping cart view.
- `src/redux/CartSlice.jsx` – Redux Toolkit slice managing cart state.
